Hospital Readmission Data Analysis

Project Objective

The objective of this project is to analyze a hospital readmission dataset using Python.
The project uses data analysis and visualization techniques to understand patterns in patient readmissions and explore the dataset using statistical methods.

Technologies Used

Python
NumPy
Pandas
Matplotlib

Dataset

Dataset used in this project : hospital_readmission_dataset.csv
The dataset contains hospital-related patient information which can be used to analyze hospital readmission patterns.

Data Visualization

The project includes the following visualizations:
Scatter Plot
Histogram
Bar Chart
Graphs are generated using Matplotlib with proper Title,X-axis label,Y-axis label,Grid and Figure size .

Output

The program will:
Display dataset summary
Calculate mean values of numeric columns
Generate data visualization graphs
Save graphs as image files
